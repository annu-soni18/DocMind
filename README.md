#  DocMind — Multi-Source RAG Chatbot

DocMind is an AI-powered chatbot that lets you chat with your documents.
Load PDFs, paste a URL, or enter raw text — DocMind indexes everything 
into a single FAISS vector store and answers your questions with source citations.

##  Features
-  Upload multiple PDFs
-  Extract content from any webpage URL
-  Paste raw text directly
-  MMR-based semantic retrieval across all sources
-  Every answer cites which document it came from
-  Streaming responses powered by Groq LLaMA-3.3-70B

##  Tech Stack
Python | LangChain | FAISS | Groq | HuggingFace | Streamlit | PyMuPDF | BeautifulSoup | Render
